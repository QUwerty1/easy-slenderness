# Модуль домашних заданий

Приложение `homework` уже присутствует в `INSTALLED_APPS`. Новые модели не изменяют
существующие модели `course` и `authorization`.

## Подключение URL

Чтобы API стал доступен, в `backend/easy_slenderness/urls.py` необходимо добавить
подключение URL модуля (это единственная необходимая правка вне `homework`):

```python
(path("api/", include("homework.urls")),)
```

Строку следует разместить рядом с `path("api/", include("course.urls"))`.
В исходном архиве этот файл намеренно не изменен из-за ограничения на изменение
уже существующего backend-кода.

## Миграции

```bash
python manage.py migrate
```

Миграция `homework/0001_initial.py` создает таблицы отчетов, приемов пищи и фотографий.

## Автоматическое закрытие отчетов

Команда:

```bash
python manage.py process_homework_reports
```

Переводит отчеты со статусом `filling`, дата которых уже прошла, в статус `review`.
Ее следует запускать планировщиком ОС раз в минуту (по аналогии с уже существующей
командой обновления состояний курсов). Список отчетов также выполняет синхронизацию
просроченных записей при обращении к API, поэтому задержка планировщика не оставляет
отчет навсегда в статусе `filling`.

Файлы фотографий сохраняются через стандартное хранилище Django в каталоге
`MEDIA_ROOT` (`backend/media/`, не попадает в git) под случайными именами. Принимаются
только JPEG, PNG и WebP — формат определяется по содержимому файла, а отдаются фото
только через `GET /api/homework/photos/<id>/` с проверкой доступа. В production
необходимо настроить постоянное хранилище файлов.
